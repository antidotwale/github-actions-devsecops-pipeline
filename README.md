# github-actions-devsecops-pipeline

GitHub Actions pipeline with secret scanning, SAST, dependency, container and IaC scans.

> Personal lab project. Built in my own AWS, Azure and GitHub accounts for learning and practice. It is not work I did for any employer or client.

## What this builds

A five layer security pipeline on a sample app, failing the build on findings, with results shown in the Security tab.
